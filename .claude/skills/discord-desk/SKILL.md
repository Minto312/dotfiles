# 窓口に頼む (discord-desk)

Discord の個人サーバーには、役割ごとの **窓口チャンネル** がある (discord-ack)。窓口には担当の
claude がいて、依頼ごとにスレッドを立てて処理し、結果をそのスレッドに書く (ユーザーが読む)。
このセッションの作業の途中で窓口の担当に任せたいことが出たら、`discord-desk ask` で頼む。

```bash
~/.local/bin/discord-desk list                      # どの窓口があるか
~/.local/bin/discord-desk ask スケジュール <<'EOF'
11/6 (金) 締切の市への提出資料のために、作業時間を 3 時間確保したい。
11/4 (水) か 11/5 (木) の午後で空いているところ。タイトルは「ORI 提出資料 (5)(6) 作成」。
関係するタスク: task-takashima #277
EOF
```

## いつ使うか

- **カレンダーのブロック** (窓口「スケジュール」): 締切から逆算した作業時間、打ち合わせの準備、移動、
  リマインドしたい日時など。スケジュールの窓口は、ユーザー自身のカレンダーへの追加・変更なら
  承認なしで進める (参加者を招待する予定・削除はユーザーの ✅ 待ち)
- そのほか、窓口の役割に当たる仕事 (`list` の説明を見る) を、このセッションで抱えずに任せたいとき

## 依頼の書き方

窓口の担当はこのセッションの会話を知らない。依頼文だけで分かるように書く:
- 何のための時間・作業か、いつまでに、どれくらいの長さか
- 希望の時間帯や避けたい時間帯、場所 (対面・オンライン)
- 関係するタスク番号・ファイルのパス・URL

## 注意

- 頼んだら、窓口に頼んだこと (どの窓口に何を) をユーザーへの報告に 1 行書く。結果は窓口のスレッドに出る
- 機密度の高い情報 (TLP:RED: 口座番号・マイナンバー等) は依頼文に書かない。パスで示す
- 窓口が無い (`list` に出ない) ときは作らない。ユーザーに伝える
