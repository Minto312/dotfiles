共通の決まり:
- 作業は、リポジトリの .claude/worktrees/<ブランチ名> に worktree を作って行う。ブランチは、担当に別の書き方がなければ <ブランチを作る元> から作る。始める前に git fetch する
- 自分の担当以外のファイルは変更しない。ほかの作業役が、同じリポジトリの別のブランチで同時に作業している
- ワークスペースの notes/ と CLAUDE.md は変更しない (記録は司令塔が行う)
- リポジトリに個人の情報や秘密の値を入れない
- コミットの作者は既定の設定のままにする。コミットメッセージと PR 本文に AI の署名 (Claude-Session、Co-Authored-By、Generated with、claude.ai/code の URL) を入れない
- 終わったら push して PR を出す。Issue があれば、PR 本文の最後に「Closes #<Issue の番号>」を書く。マージはしない (マージの許可は司令塔が受ける)
- 自分では決められないことがあれば、このペインでユーザーに直接聞く (AskUserQuestion を使うか、質問を返答に書いて止まる)。ユーザーはこのペインで答える。質問を司令塔に回さない
- 頼まれていないもの (道具、設定の変更、範囲外の変更) は作らない
- 最後の返答は 15 行以内にし、ブランチ、PR の URL、やったこと、残したこと、ユーザーに聞いたことを書く
